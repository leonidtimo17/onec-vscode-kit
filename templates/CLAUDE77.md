# 1С:Предприятие 7.7 — база «{{BASE_NAME}}»

Проект для доработок базы 7.7. Создан `tools/v8dev.py init --v77`. Каталог базы: `{{BASE_DIR}}`.
Исходники {{SRC_STATE}}.

## Железные правила

- Это 1С 7.7, НЕ 8.x: нет управляемых форм, расширений, типа Булево, `Новый`, `Попытка` в 8-м смысле.
  Синтаксис — по скилу `1c77-dev` (ловушки: `ПустаяСтрока`, `СоздатьОбъект`, тернарник `?()`).
- ЕСЛИ правишь `.1s`, `.frm`, `.mdp`, ТО сохранять в кодировке CP1251 — как после разбора GComp.
  Обычный grep кириллицу в CP1251 не находит: искать через python с явной кодировкой.
- ЕСЛИ нужно собрать `1Cv7.MD` или `.ert` обратно, ТО только рабочим GComp (с `GComp.dll` рядом) через
  PowerShell, в копию файла; затем сверить, что у файла изменились размер и время. Оригинал в каталоге
  базы не перезаписывать — подмену делает пользователь при закрытой 1С.
- Ничего не делать в каталоге базы `{{BASE_DIR}}` без явной просьбы пользователя.

## Структура

| Путь | Что это |
|---|---|
| `raw/1Cv7.MD` | Копия конфигурации (бинарная) |
| `raw/**/*.ert` | Копии внешних отчетов и обработок |
| `src/MD/` | Разобранная конфигурация: модули `.1s`, формы `.frm`, метаданные `.mdp` |
| `src/ExtForms/<Имя>/` | Разобранные внешние отчеты и обработки |
| `tools/v8dev.py` | `refresh` — заново скопировать и разобрать после изменений в базе |

## Цикл доработки

1. Найти нужный модуль в `src/`.
2. Править `.1s` / `.frm` (CP1251).
3. Собрать `.ert` или `1Cv7.MD` GComp во временный файл (`build/`), проверить размер и время.
4. Пользователь подменяет файл при закрытой 1С и проверяет. Закоммитить изменения в git.
